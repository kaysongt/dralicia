# Dr. Alicia Unified Website Hub (Vite)

Production-ready starter powered by Vite.

## Run locally
```bash
npm install
npm run dev
```

App runs on:
- Local: `http://localhost:4173`
- Network/Tailnet-ready bind: `0.0.0.0:4173`

## Build
```bash
npm run build
npm run preview
```
